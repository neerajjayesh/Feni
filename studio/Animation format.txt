FENI STUDIO - ANIMATION FILES

Prepare numbered PNG frames at exactly 160 x 128 pixels, e.g. 0001.png,
0002.png, 0003.png. Use 10-15 frames per second for a starting point.
In Studio: Library > Pack PNG frames. Select the folder, frame rate and an
output .fna file in your chosen animation folder. Originals are never changed.
The packer uses one 16-colour palette across the clip. Transparency is composited
onto black. Simple flat artwork produces smaller, clearer files.

For MP4 sources, export frames using your video editor, or FFmpeg:
ffmpeg -i input.mp4 -vf "fps=12,scale=160:128:force_original_aspect_ratio=decrease,pad=160:128:(ow-iw)/2:(oh-ih)/2:black" frames/%04d.png
Create the frames folder first. Export a short clip, not a full-length video.

Supported limits:
- 160 x 128 pixels, landscape
- 16 RGB565 colours shared by the clip
- 1-20 fps (10-15 recommended initially)
- Maximum 300 frames, 30 seconds, 512 KiB per file
- Startup, PC connected and wake: maximum 10 seconds; these play once
- Sleeping, gaming, coding, idle and custom clips loop
- Menus, clock and alerts take priority. FLASH remains responsive.
- File storage is shared across all clips; Device shows available capacity.

Assign files under Animations and click Send selected or Send all assigned.
Saving a local assignment does not upload it. Empty assignments do not erase
device files. Restore built-in explicitly removes the selected device clip only.
Custom 1-8 slots can be assigned to rules in App rules. First matching enabled
rule wins. Foreground is recommended for Steam and coding editors.

BINARY FNA1 FORMAT (for other converters)
All integer values are little-endian.
Offset  Size  Meaning
0       4     ASCII FNA1
4       2     Width = 160 (uint16)
6       2     Height = 128 (uint16)
8       2     Frames per second, 1-20
10      2     Frame count, 1-300 and <= fps * 30
12      4     Reserved; must be zero
16      32    16 palette entries, each uint16 RGB565 (R5 G6 B5)
48      ...   Frames in order

Each frame starts with a uint32 payload byte count, followed by runs:
uint16 repeat_count (1-20480), uint8 palette_index (0-15).
Runs cover exactly 20480 pixels in row-major order, top-left to bottom-right.
Payload length is a nonzero multiple of 3 and at most 61440 bytes.
There is no per-frame padding, audio, trailing data, or alpha channel.
The device validates every frame before replacing the previous slot file.

Command line packing:
"Feni Studio.exe" --pack "C:\My animations\frames" "C:\My animations\gaming.fna" 12
"Feni Studio.exe" --validate "C:\My animations\gaming.fna"
The process exits 0 on success, 1 on failure. CLI errors are also written to
%TEMP%\feni-studio-error.log.
